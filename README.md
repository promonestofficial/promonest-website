# PromoNest starter

A modern, responsive Next.js starter for a worldwide coupon and deals website.

## Run locally
1. Install Node.js 20 or newer.
2. In this folder run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy free
1. Create a GitHub account and a new repository.
2. Upload these project files to the repository.
3. Sign in to Vercel using GitHub and import the repository.
4. Deploy using the default Next.js settings.
5. Your free address will look like `promonest.vercel.app` (if available).

## Important before launch
- The coupon codes, discounts, expiry dates and brands in this demo are illustrative placeholders. They are NOT confirmed active deals. Replace them with offers you have permission to publish and test every code.
- The admin page is only a visual preview. It has no login, database, or save/edit capability yet.
- Before collecting or storing real user/admin data, connect a database (e.g. Supabase), implement secure authentication, and add privacy/terms/contact pages.
- Update `metadataBase`, robots and sitemap URLs if your final domain changes.
- Add official retailer affiliate links only after joining the relevant affiliate programs and following their terms.
- No SEO ranking is guaranteed. Useful original store content, accurate offers, crawlable pages and quality links matter.
